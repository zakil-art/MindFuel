 MindFuel App

 Description
 
MindFuel is a mobile application that helps users track their daily moods and emotions. 
The app stores user entries in a Firebase database and allows users to view their mood history.

 Features
- User login screen
- Mood tracking system
- Save entries to Firebase
- View history of past moods
- Simple and clean user interface

 How it Works
The user logs into the app, enters their mood, and the data is saved in Firebase. 
The saved data is then displayed in the history screen for review.

 Technologies Used
- Kotlin
- Android Studio
- Firebase (Firestore/Realtime Database)
- Jetpack Compose

 Screens
- Splash Screen
- Login Screen
- Main Screen
- History Screen
- Insights Screen
